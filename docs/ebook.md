# 小喵掌机 eBook（电子书）功能说明

> 在现有 MP3 / SD / 蓝牙 / 设置四页 UI 基础上，新增"电子书"功能：从 MicroSD 读取 UTF-8 纯文本（.txt），以页为单位阅读，带进度显示。本文档为**实现现状说明**（已全部落地，随代码更新）。

## 1. 目标与范围

- 在 320×240 ST7789 屏幕上以 16px 全字库 CJK 字体渲染 TXT 电子书。
- 支持 UTF-8 编码（含中英混排、全角标点），自动换行、分页。
- 支持多本书切换、按页顺序阅读。
- 交互与现有页面风格一致（BIOS 风格菜单、A/B/方向键、toast 提示）。

## 2. 硬件约束与版面参数（定稿）

| 项目 | 数值 | 影响 |
| ---- | ---- | ---- |
| 屏幕 | 320 × 240 | 每行最多 20 个 CJK 字符（16px/字，满屏） |
| 字体 | lv_font_cn_16（16px，行高 22） | 文本区 176px → 每页 **8 行** |
| SD | SDSPI 共用 SPI2，10MHz（`SD_SPI_MAX_FREQ_KHZ=10000`） | 不能整书载入，按页随机读 + 页起始偏移历史环 |
| RAM | PSRAM 8MB（WROVER-B） | 页文本、块缓冲、书名列表全放 PSRAM |
| 按键 | 上/下/左/右/A/B | 阅读页：A/右=下一页，左=上一页，B=返回书列表 |

```text
标题栏：  y = 2     左侧书名（去扩展名，截断），右上角页码（当前页/总页，总页未算完只显当前页）
分隔线：  y = 34
文本区：  (0, 36)   尺寸 320×176（8×22，容纳 8 行 × 22px 行高，y=36 ~ 212），满屏宽度
状态行：  y = 214   左端 15 格文本进度条（x=8 起，宽 ~110px）+ 右端百分比（x=272 起 40px 宽，右对齐 x=312）；翻页 toast 临时占用
```

**行宽/行高计算：** 320px（= LCD_H_RES，满屏）内，CJK（3 字节 UTF-8）= 16px，ASCII 按字体实际度量（半宽不等，见 4.2）。最多 20 个全角字符/行。为提升阅读密度，文本区采用 176px（8 行 × 22px）布局，通过 `text_line_space=-8` 把 `lv_font_cn_16` 的默认 30px 行高压到 22px（早期版本曾用 150px/5 行 × 30px）。

> 初稿按 lv_font_cn_10（10px，18px 行高）设计，实际 UI 统一使用 lv_font_cn_16，
> 已按真实字体修正：行宽 320px（满屏）、行高 22px、每页 8 行。

### 4.2 分页模型（关键算法）

分页是**确定性**的（不依赖 LVGL 布局结果），保证翻页与总页数计算一致。

1. **窗口式读者（reader_t）**：4KB 块缓冲（`EBOOK_CHUNK`）作为连续窗口，`base+pos` 定位；解码逐字符顺序推进，绝不后退，单次顺序扫描即可完成一页布局。所有书共用同一 reader。
2. **字符规范化**：打开时 strip UTF-8 BOM；`\r` 跳过（CRLF→LF）；`\t` 展开为空格。
3. **行宽计量**：ASCII 用 lv_font_cn_16 字体的真实 advance 表（`s_ascii_w16`，1/16px 精度，逐字抄自字体 glyph_dsc），非 ASCII 一律 256/16=16px——读者换行结果与 LVGL 渲染完全一致。**例外表 `s_typ_w16`**：字库新增的少量非全宽排印符（`—`=228、`–`=137、`“`=117、`ʼ`=52 等共 16 项，取自 glyph_dsc 全部非 256 的码点）按其真实 advance 计量，避免与渲染错位；CJK/平假名/全角 FF00·3000 均为 256。
4. **换行规则（仅保源换行 + 宽度溢出硬断）**：排版引擎**无任何字符类 / 标点 / 词规则层**。一条显示行只在以下两处之一结束：
   - **源文件换行**（mandatory）：遇到 `\n` / 单独 `\r` / CRLF 立即结束本行（取归一化后的下一偏移），原样保留——作者在哪里敲了回车，读者就在哪里看到换行；
   - **宽度溢出**（hard break）：下一个字 glyph 的累计宽度将超出 320px（满屏）时，**在该字之前硬断**，使本行填满到极限；被断开的字顺延到下一行行首。
   其它一律不影响断行：
   - 空格：行首空格跳掉不排；行末摆不下的尾随空格丢弃；
   - 没有"词完整性""行首禁则""`--` 保护"等概念——英文长词在宽度处会被从中间拆断，标点（含 `，` `、` `--` 等）均可落在行首或行尾，按源文本顺序紧凑填充。
   - **标点压缩（仅宽度计量，非断行规则）**：全角标点**无论行中还是行尾**一律按半宽渲染——`。、！？；：）〉》」』】”’` 共 15 项替换为 ASCII 近似形（`.` `,` `!` `?` `;` `:` `)` `>` `]` `"` `'`），宽度按字体真实 advance 计量（256 → 52~105，即 1/16px），仅影响"何时填满一行"，不改变断行位置规则；无窄形的禁则标点（`…` 等）按原样全宽并入。
5. **一页 = 恰好 8 行**（`EBOOK_PAGE_LINES`）；最后一页末尾的尾随空格丢弃；`layout_page()` 返回下一页起始字节偏移（EOF 处 == 书大小）。

> 换行完全由"源文本换行符 + 行宽上限"决定，没有任何字符属性分类层；翻页与后台总页数计算仍逐字节一致（确定性不破坏）。

```text
页结构：
  s_cur_start / s_next_start   （当前页 / 下一页起始偏移）
  s_hist[32]                   页起始偏移历史环（后退导航）
```

### 4.3 翻页与缓存（性能）

```text
下一页：hist_push(当前偏移) → seek(s_next_start) → layout_page()
上一页：hist_pop() 取上一页偏移 → seek → layout_page()
        历史环耗尽（深度后退）→ rebuild_history()：从头顺序布局重建
        全部页起始偏移（只到当前页为止，约 O(页数) 次布局，一次性成本）

总页数：独立后台任务（count_task）用第二块 4KB 缓冲顺序布局全书
        代数守卫 s_open_gen：换书时放弃旧结果；算完 bump count_version
```

- 页文本缓冲：1KB（`EBOOK_PAGE_BUF`，PSRAM `EXT_RAM_BSS_ATTR`）。
- 块缓冲：4KB × 2（`heap_caps_malloc(..., MALLOC_CAP_SPIRAM)`，失败退回内部 RAM），主读者与计数任务各一块。
- 向后翻页无需重读整页布局，历史环命中即 O(1)；环只存 4 字节偏移（ESP32 `size_t`）× 32 = 128B。

### 4.4 阅读进度持久化（续读）

参照主流阅读器的做法，并按纯 TXT 的约束做了降级：

| 来源 | 做法 | 本项目 |
| ---- | ---- | ---- |
| KOReader | `partial_md5 = size + 头 1KB + 采样` 做身份；`*.sdr/metadata.lua` sidecar | 借鉴内容指纹 |
| Kindle | `.sdr/<book>.mbp` + 百分比双锚点 + Whispersync 云同步 | 借鉴双锚点；无网络，不做云同步 |
| 微信读书 / Apple Books | EPUB CFI 结构标识符（不受重排版、字体、屏幕影响） | TXT 无 DOM，降级为「偏移 + 上下文片段 + 百分比」三级 |
| NVS | 进度存 flash | 不采用：换卡/换设备进度要跟着书走，且 flash 有擦写次数限制 |

#### 4.4.1 身份：内容指纹，不用路径

```text
fp = FNV-1a64( size(8B) ‖ 头 1KB ‖ 尾 1KB )
```

- 书改名、移到别的子目录、SD 卡重新拷贝、换卡重排 → 指纹不变 → **进度跟着书走**（旧实现用路径哈希，这些场景全部丢进度）
- 路径只作附加索引 `path_h`（FNV-1a32）供书列表零 IO 显示百分比用；碰撞最多少显示一个百分比，永远不会定位错书
- 成本：打开书时 2 次 seek + 2KB 读（约 1–3 ms）

#### 4.4.2 存储：定长槽数组 + 每槽 CRC

```text
/sdcard/eBook/.progress.v2
  [16B 头]  magic "EBPF" / version / slot_sz / slot_count
  [slot 0] … [slot 511]          每槽 72B

slot = { fp(8) path_h(4) off(4) seq(4) ctx[16] name[32] pct(1) flags(1) crc(2) }
```

- 保存 1 本书 = **1 次 72B 定位写**（1 个 4KB FAT 扇区），不再重写整表（旧实现每次写 8KB）
- 每槽自带 CRC16-CCITT + 单调序号：坏扇区只毁 1 本书；刻意不做全局校验和，否则每次保存都要重写它，单槽写就失去意义
- 不用 tmp + rename：单槽原地写，掉电最多损坏正在写的那一槽
- 槽满则淘汰 `seq` 最小者（最久未读）
- `fflush` + `fsync` 显式落盘（`CONFIG_FATFS_IMMEDIATE_FSYNC` 未开，不显式同步就只停在文件缓存里）

#### 4.4.3 恢复：四级回退

| 级别 | 判定 | 结果 | 典型场景 |
| ---- | ---- | ---- | ---- |
| ① `EXACT` | `off` 仍是行首，且该处 16 字节 == 存的 `ctx` | 精确回到原页 | 正常关机；书改名 / 移动 / 换卡 |
| ② `DRIFT` | 在 `off ± 8KB` 内搜索到 `ctx`（命中后回退到行首） | 找回原位置 | 文件前面增删了段落 |
| ③ `PERCENT` | 按存的 `pct` 定位（回退行首 + 逐页布局到目标页） | 回到大致位置 | 转码 GBK↔UTF-8、加 BOM、CRLF 规范化 |
| ④ `NONE` | 以上都不成立 | 第 1 页 | 文件被整体重写、首次打开 |

② 的 16KB 扫描是顺序经过 reader 窗口的（约 4 次块填充），且只在 ① 失败时发生一次。恢复方式由 `ebook_resume_kind()` 暴露给 UI，toast 区分「已续读 N%」「已重新定位 N%」「文件已变 跳至 N%」。

#### 4.4.4 页码不再持久化

旧实现把页码写进进度表，但跳转后的页码只是估算值（`pct × 总页数`），存下来后下次续读被当成真值显示，导致「X/N」长期错乱。现在：

- 槽里**不存页码**
- 定位后用 count 任务的页起始表 `s_start_table` **二分**查出规范页码（分页是确定性的，与 UI 读者的页严格一致）；跳转后的非规范序列误差 ≤ 1 页
- 表尚未覆盖当前位置 → 暂用 1（跳转后则用百分比估算），置 `s_page_calib`；`ebook_page()` / `ebook_page_flip()` 里惰性校准，表一就绪立即换成精确值

#### 4.4.5 保存时机

| 时机 | 行为 |
| ---- | ---- |
| 翻页后 | 防抖 **1.5s**（`EBOOK_SAVE_DELAY_MS`） |
| 累计翻 10 页 | 强制落盘（`EBOOK_SAVE_FORCE_PAGES`，连续翻页会一直重置防抖） |
| 退出阅读页 / 换书 / `ebook_close()` | 同步保存；失败时 UI 提示「进度保存失败」 |
| 卡拔出 / 写失败 | 置 `ebook_save_failed()`（sticky）并打日志；SD 无卸载回调，无法做到零丢失 |

#### 4.4.6 v1 进度迁移

旧格式 `/sdcard/eBook/.progress`（magic `EBPG`，路径 48 位 FNV-1a 的 MRU 表）**保留、只读、不删**：

- v2 查不到时查一次 v1（路径哈希 + 文件大小匹配）；v1 没有 `ctx`，只能做弱校验
- 命中则用其 offset 并回退到最近行首，下次保存即写入 v2，迁移完成
- 迁移单向且可随时中断，v1 文件可在电脑上手工删除

### 5.2 书列表页（复用 MP3 列表版式）

两级视图，同播放器：先选来源，再浏览书目。

```text
来源选择                      书目浏览

  四大名著                      三国演义

  武侠小说                      朝花夕拾
    选择阅读来源    A进入          [四大名著] 4 本  A打开
```

- 来源 = `<ALL>`（整个 `/sdcard/eBook` 树，递归）+ `/sdcard/eBook` 下每个顶层子文件夹（各为一个来源，SD 热插拔/重进页面时重新发现，同 `ui_discover_sources`）；
- 进入某来源后后台递归扫描该目录（不区分大小写，同播放器：stat 判定目录并下钻，深度 ≤16，跳过隐藏项），收集全部 `.txt`（最多 512 本，超出截断）；qsort 排序 = 先按文件名长度（短在前）再按文件名忽略大小写字典序（strcasecmp），文件名相同（不同子目录同名书）按完整路径兜底，跨扫描稳定；
- 状态行显示当前来源名（`<ALL>` 显示为"整卡"）+ 书目数，如 `[四大名著] 4 本`；扫描中显示"扫描中..."；
- 列表显示名去路径（仅文件名）；最多显示 6 行，滚动窗口同 MP3 列表；
- B：书目视图返回来源选择（同播放器曲目列表），来源选择再按 B 回主菜单；
- 打开失败提示"打开失败"；打开成功进入阅读页，书名（去扩展名）先捕获到 `s_eb_open_name`，后续扫描不改变标题。
- **续读**：详见 4.4。要点：按**内容指纹**（而非路径）寻址，改名 / 移动 / 换卡都能续读；位置保存为「页起点偏移 + 该处 16 字节上下文 + 百分比」，恢复按 精确 → 邻域搜索 → 百分比 → 从头 四级回退；存储在 `/sdcard/eBook/.progress.v2`（512 槽 × 72B 定长数组，每槽自带 CRC + 序号，保存只写 1 槽）；翻页后 1.5s 防抖保存，累计 10 页强制落盘，换书 / 退出阅读页（B）同步保存；toast 按恢复方式区分「已续读 N%」「已重新定位 N%」「文件已变 跳至 N%」，保存失败提示「进度保存失败」；阅读页按 Select 呼出跳转界面（见 5.4），跳转 0% 即从头并覆盖进度；旧版 `.progress`（v1）保留只读，打开时惰性迁移。


- **标题栏**：左侧书名（去扩展名，截断），右上角页码"当前页/总页"（总页数后台算完前只显"当前页"）；
- **文本区**：8 行，单 Label（`LV_LABEL_LONG_MODE_CLIP`，320×176 满屏，引擎按 22px 行高排好 `\n` 连接；176 = 8×22，完整容纳 8 行），全角字符渲染；全角标点（行中/行尾）以半角近似形显示（标点压缩，见 4.4 宽度计量）；排版仅保留源文本换行 + 行宽溢出硬断（见 4.4），英文长词可能在宽度处被拆断，标点可落行首/行尾；
- **状态行**：左端 15 格文本进度条（x=8 起，`=` 已读、`-` 未读，每格 ≈ 6.7%，格子数按百分比四舍五入），右端百分比右对齐到 x=312（x=272 起 40px 宽，可容纳 "100%" ≈36px，避免 32px 旧宽度下左端 "1" 被裁成 "00%"）；翻页瞬间整个状态行被 toast（"下一页/上一页/第一页/最后一页"）临时替换（进度条与百分比隐藏），遮挡 SD 读取延迟。

> **为什么用文本指示器替代 LVGL `ui_bar`**：进度条（`ui_bar`）是图形 widget，占用状态行高度、且与 BIOS 风格不符；改为状态行左侧一行纯文本，全 ASCII 字符（`[ = - ]`）由现有字体保证渲染，无字形缺失风险，15 格分辨率对"剩余阅读量"的感知足够。

### 5.4 按键映射

| 按键 | 书列表页 | 阅读页 |
| ---- | ---- | ---- |
| 上 / 下 | 移动选择 | （预留） |
| A | 打开所选书 | 下一页（末页提示"最后一页"）；跳转界面中：确认跳转 |
| 左 | — | 上一页（首页提示"第一页"）；跳转界面中：目标百分比 −1% |
| 右 | — | 下一页；跳转界面中：目标百分比 +1% |
| B | 返回主菜单 | 返回书列表（立即保存进度）；跳转界面中：取消跳转 |
| Select | — | 呼出跳转界面（见下） |

**跳转界面**（无数字键盘的替代方案）：阅读页按 Select 呼出，hint 行显示"跳转至 N% 左/右调 A确认 B取消"，初始值为当前进度；左/右以 1% 步进调整（长按自动连续），A 确认后跳到目标百分比位置并 toast"已跳转至 N%"，B 取消留在原页。跳转实现：目标字节 = 文件大小 × N%，向前回退到最近换行（超 2 块窗口未遇换行则回退 ~1KB 兜底），逐页布局定位到包含目标的页起点（通常 1~2 页），页码按 N% × 总页数估算（字节进度条为权威），随后正常保存进度。跳转 0% = 从头开始（覆盖旧进度），跳转 100% = 最后一页。

## 6. 内存与性能预算（实际）

| 项 | 大小 | 位置 |
| ---- | ---- | ---- |
| 书名列表（512 本 × 320B，双缓冲工作区） | 320KB | PSRAM（EXT_RAM_BSS_ATTR） |
| 进度槽数组（512 槽 × 72B） | 36KB | PSRAM（EXT_RAM_BSS_ATTR） |
| v1 迁移表（512 × 24B，惰性加载） | 12KB | PSRAM（EXT_RAM_BSS_ATTR） |
| 指纹采样缓冲 | 1KB | PSRAM（EXT_RAM_BSS_ATTR） |
| 页文本缓冲 | 1KB | PSRAM（EXT_RAM_BSS_ATTR） |
| 块读取缓冲 × 2（主读者 / 计数任务） | 4KB × 2 | PSRAM（失败退回内部 RAM） |
| 页偏移历史环 | 128B（32 × 4B） | 内部 RAM |
| 扫描 / 计数 / 进度保存任务栈 | 4KB × 3 | — |
| 翻页耗时 | 读 ~1KB + 布局 8 行 | 典型 < 20ms（历史环命中时零重复布局） |

> 新增 DRAM 占用 < 5KB，对现有 60fps 部分刷新双缓冲无影响；SD 读发生在翻页瞬间，toast 遮挡期间完成。

## 8. 风险与对策

| 风险 | 对策 |
| ---- | ---- |
| SDSPI 翻页卡顿 | 历史环 + 4KB 块缓冲；toast"下一页"遮挡读取延迟 |
| 深度后退慢（>32 页） | 首次触发 rebuild_history 从头布局重建，之后恢复正常 |
| 生僻字超出字库（22000 字覆盖） | 缺字以 LVGL 默认占位，不中断 |
| GBK 文本 | 未检测；按 UTF-8 解码会出现个别错字（已知限制） |
| 超大文件（>16MB）总页数计算慢 | 总页数后台任务计算，期间只显"第 X 页"，不阻塞翻页；换书即时放弃旧任务 |
| 无 SD 卡 | 书列表为空，状态行提示"无TXT文件" |
| 进度指纹计算拖慢打开书 | 只读头尾 2KB（约 1–3ms），被打开流程掩盖 |
| 邻域搜索 ±8KB 卡顿 | 只在精确匹配失败时触发一次；顺序经过 reader 窗口，约 4 次块填充 |
| 拔卡瞬间丢进度 | 防抖降到 1.5s + 累计 10 页强制落盘 + 显式 `fsync`；SD 无卸载回调，无法做到零丢失 |
| 文件被改写导致续读错位置 | 上下文片段校验 + 四级回退，最差降级到百分比定位，不会静默跳到无关位置 |

## 9. 附录：测试样例要求

1. 纯中文长文（>100KB）分页正确、翻页无错位；
2. 中英混排（代码注释类文本）行宽不超界；
3. UTF-8 BOM / 无 BOM 文件均可读；
4. CRLF 与 LF 混合文件换行正常；
5. 翻 100 页后翻回第 1 页，无错位（验证历史环重建）；
6. 中文书名 + 英文书名排序稳定（文件名长度优先，同长度字典序）；
7. 无 SD 卡时书列表为空，状态行提示"无TXT文件"，不崩溃；
8. 续读：读到某处退出再打开，回到同一页，toast"已续读 N%"，页码与总页数一致；
9. 书改名 / 移到别的子目录后重新扫描，仍能续读（验证内容指纹，而非路径）；
10. 在文件**开头**插入或删除一段文字后打开，能重新定位到原位置（验证 DRIFT 邻域搜索）；
11. 把文件整体重排版或转码后打开，降级到百分比定位且不崩溃（验证 PERCENT）；
12. 存在旧版 `/sdcard/eBook/.progress` 时首次打开书，进度迁移到 `.progress.v2`；
13. 保存中拔出 SD 卡：不崩溃，退出阅读页时提示"进度保存失败"。
