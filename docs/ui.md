# 小喵掌机 UI 与交互说明

> 本文档为**实现现状说明**（随代码更新）：描述 LVGL 9.5 自绘 UI 的页面结构、布局参数与按键映射。

## 1. 总体结构

```text
components/app/ui/
  ├─ ui_theme.h/.c        设计令牌层：色板、间距、行高、版面区段 + 基础控件工厂
  │                       （ui_theme_page / ui_theme_label / ui_theme_bar /
  │                        ui_theme_separator / ui_theme_text_set）
  ├─ ui_widgets.h/.c      组件层：ui_list_t 列表视图（光标列 + 文本列 + 滚动窗口
  │                       + 焦点着色），被音乐源/曲目、蓝牙设备、电子书源/书籍
  │                       四张列表共用
  ├─ ui_nav.h/.c          导航层：页面栈（前进 ui_go() 入栈，B 键沿栈回退）
  ├─ ui_internal.h        页面与装配层之间的私有契约：ui_state_t（屏幕级控件
  │                       状态）、共享工具函数、各页对外接口
  ├─ ui_pages_player.c    音乐源选择 / 曲目列表 / 悬浮播控面板（含跑马灯）
  ├─ ui_pages_ebook.c     电子书源选择 / 书列表 / 阅读页（含跳转浮层）
  ├─ ui_pages_settings.c  设置项表（分组两级视图）+ NVS 持久化 + 各项回调
  ├─ ui_pages_bt.c        蓝牙设备扫描 / 配对 / 连接
  ├─ ui_pages_launcher.c  首页：3×2 图标宫格（音乐/电子书/蓝牙/设置）
  └─ ui.c                 装配层：屏幕、首页（Launcher）、电量表、按键路由、刷新调度
```

- 页面文件各自持有本页状态（选中项、滚动窗口、跑马灯、paint guard），只向 `ui.c` 暴露 build / refresh / 按键处理接口（见 `ui_internal.h`）；装配层不再知道页面内部的变量名。
- 进入页面时的准备工作（设置页重查缓存、播放器加载播放列表缓存、蓝牙栈上电）随页面走，放在各自的 build 函数里。

- 入口：`ui_create()` 在 LVGL 任务中调用一次；`ui_refresh()` 由任务循环以 16ms 周期调用（`UI_REFRESH_PERIOD_MS`，main.c）。
- **按需刷新**：`s_ui_dirty` 脏标记 + `ui_external_changed()` 轮询（蓝牙设备列表/版本、配对状态、SD 挂载、播放器状态、电子书扫描/页数版本），只在真变化时重建页面内容；`ui_theme_text_set()` 对未变化的文本直接跳过 LVGL set，60Hz 空转不产生重绘。
- 页面切换 `ui_enter_page()`：销毁旧页容器 → 按 `UI_PAGE_*` 重建 → 强制重绘。它**不动导航栈**：前进用 `ui_go()`（先入栈再显示），后退用 `ui_nav_back_or_menu()`（先出栈再显示父页，栈空则回主菜单）。分开是为了避免后退时重复入栈把用户困在子页。
- 页面内的两级视图（播放器的「源选择 ↔ 曲目列表」、电子书的「源选择 ↔ 书列表」）不入栈：B 先在页内退回上一级视图，退到最外层才交给导航栈。
- `ui_show_menu()` 现在显示 Launcher 首页（清导航栈）。
- 主题色与几何全部集中在 `ui_theme.h`（色板见 §3.2，版面区段见 §3.1）。**换肤只改这一个文件。**

## 2. 页面清单

| 页面 | 枚举 / 形态 | 用途 | 构建函数 |
| ---- | ---- | ---- | ---- |
| 首页（Launcher） | menu 态（非 `UI_PAGE_*`） | 3×2 图标宫格：音乐 / 电子书 / 蓝牙 / 设置 | `ui_build_launcher` |
| 播放器 | `UI_PAGE_PLAYER` | MP3 列表（源选择 ↔ 曲目列表）+ 播放状态 | `ui_build_player` |
| 书列表 | `UI_PAGE_EBOOK_LIST` | 先选来源（`<ALL>`+子目录），再递归扫描 `/sdcard/eBook/**/*.txt` | `ui_build_ebook_list` |
| 阅读 | `UI_PAGE_EBOOK_READ` | TXT 电子书分页阅读 | `ui_build_ebook_read` |
| 蓝牙 | `UI_PAGE_BT` | A2DP 设备扫描/配对/连接（**顶层入口**，不再埋在设置子页） | `ui_build_bt` |
| 设置 | `UI_PAGE_SETTINGS` | 分组两级视图：音频（音量/总增益）/ 显示（背光/息屏）/ 系统（重建列表/恢复出厂/清除进度）/ 日志 | `ui_build_settings` |

- Launcher 是 3×2 宫格，目前启用 4 格（第一排 音乐 / 电子书 / 蓝牙，第二排 设置），第 5、6 格留空。A 进入选中页；左右按行主序回绕（走到行尾跨到另一排），上下换行且在两排间循环（第一排按上回绕到第二排、第二排按下回绕到第一排），换行时取该方向最近的有效格。
- Launcher 选中态：选中 tile 底色换 `UI_COLOR_PANEL`、边框 accent 2px、标题与图标染 accent；另有一个 accent 小圆点光标钉在选中 tile 右上角，切换选中时以 150ms 缓动平滑滑动。
- 蓝牙在 Launcher 有独立顶层入口，进入即懒启动蓝牙栈；设置页不再有蓝牙开关项——蓝牙主开关（`bt_on`）由蓝牙页自身管理。
- 设置页两级视图：分组列表 → 该组项列表，B 先在组内退回分组、再退回首页；进入组内项的左侧调整继续走各 `on_lr` 回调。
- 全局 **mini player bar**：非播放页且正在播放时，在 y=196 状态行位置显示 `> 曲名 … 音量%`，与页面自身状态行（电子书/蓝牙状态）互斥；播放停止即让位。它挂在 screen 上、跨页面存活。
- 电子书引擎在 `app/ebook/ebook.c`，UI 通过 `ebook.h` 公开 API 交互（见 `docs/ebook.md`）。

## 3. 版面与配色

### 3.1 三段式版面（常量全部在 `ui_theme.h`）

```text
状态栏    y 0 .. 33    左：页面标题；右：页面状态 + 电量表（x>=250 归电量表）
分隔线    y = 34       1px，整屏宽
内容区    y 36 .. 215  列表 6 行（首行 y=38，行距 26）/ 设置 8 行（行距 20）
                       页面状态行（曲目/书数/蓝牙状态）y = 196
                       阅读正文 y=36 起 176px（8 行 × 22px）
提示条    y 216 .. 239 按键提示（y=218），toast 临时占用同一行
mini bar  y 196 .. 215  全局常驻：非播放页 + 播放中时显示 `> 曲名 音量%`，
                       与页面状态行（电子书/蓝牙状态）互斥
```

- 全局字体 `lv_font_cn_16`（16px 全字库 CJK，`components/fonts/lv_font_cn_16.c`，行高 30）；阅读页文本区压缩到 22px 行高（`line_space = -8`）。
- 所有文本 label 默认 304px 宽（`UI_TEXT_W`）、`LV_LABEL_LONG_MODE_CLIP` 截断；列表行文本 288px 宽（`UI_LIST_TEXT_W`）。

### 3.2 色板（深色主题）

| Token | 值 | 用途 |
| --- | --- | --- |
| `UI_COLOR_BG` | `0x0B0E14` | 屏幕 / 页面背景 |
| `UI_COLOR_PANEL` | `0x1E2632` | **聚焦行填充**（焦点的主要视觉） |
| `UI_COLOR_SURFACE` | `0x151A22` | 卡片、浮层面板填充 |
| `UI_COLOR_LINE` | `0x2A323D` | 分隔线、边框 |
| `UI_COLOR_TEXT` | `0xE6EDF3` | 主文本 |
| `UI_COLOR_TEXT_DIM` | `0x8B949E` | 次要 / 未聚焦文本 |
| `UI_COLOR_ACCENT` | `0x22D3EE` | 焦点与强调（**唯一含义，不作装饰**） |
| `UI_COLOR_WARN` / `OK` | `0xFF9F43` / `0x3FB950` | 警告 / 正常 |

- **焦点态是三重编码**：整行填充（`UI_COLOR_PANEL`）+ `>` 光标 + 强调色文本。没有触摸屏，填充色是滚动列表时眼睛最先抓到的信号。
- 背景保持低饱和：屏幕走 40 行部分刷新，大面积高饱和色块会实打实增加 SPI 刷屏时间，颜色预算花在小元素上（焦点条、状态、电量）。
- 换肤只改 `ui_theme.h`；页面代码不出现任何颜色字面量。

## 4. 按键映射

按键经硬件层消抖（见 `docs/hardware.md`）映射为 LVGL key：上/下/左/右/A(ENTER)/B(ESC)。

| 按键 | 主菜单 | 播放器 | 书列表 | 阅读页 | SD 卡 | 蓝牙 | 设置 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 上 / 下 | 移动选择 | 播放中=音量±；空闲=选曲 | 移动选择 | （预留） | — | 移动选择 | 移动选择 |
| 左 | — | — | — | 上一页 | — | — | 减小数值 |
| 右 | — | — | — | 下一页 | — | — | 增大数值 |
| A | 进入页面 | 播放/暂停 | 打开书 | 下一页 | 重扫 | 连接/断开/重扫 | 进入组 / 执行项 |
| B | — | 播放中=停止；空闲=回菜单 | 回主菜单 | 回书列表 | 回主菜单 | 回主菜单 | 回主菜单 |

- 阅读页：A 与 右键均为下一页，左键上一页；首页/末页时 toast 提示"第一页/最后一页"（不翻页）。
- 播放器音量：低于 10% 时 1% 步进（精细），之上粗步进（上下 5%、左右 10%）；播放中上下键才调音量，空闲时上下键移动选择。

## 5. toast 与按键反馈

- `set_action(msg)`：toast 在下一次刷新立即可见，显示 `UI_ACTION_MSG_MS=850ms`；快速连按只更新文字并顺延过期时间，不反复延迟。toast 期间 `s_ui_dirty` 保持置位，保证过期后刷新回正常文本。
- toast 与普通状态行共用 `s_ui.hint`：`ui_set_hint(normal)` 在 toast 激活期显示 toast，否则显示 normal。
- 阅读页 toast（下一页/上一页/第一页/最后一页）临时替换进度行，遮挡 SD 读取延迟。

## 6. 播放器页布局

```text
y=2    标题 "Music Player"（橙）        右上 ">> / || / --"（播放状态）
y=38..158  曲目列表 4 行（选中青色）
y=172   "空闲" / "无MP3文件" / 当前曲目名
y=204  "上/下选择 A播放 B返回" / "上/下音量 A暂停 B停止"
```

- 曲目列表由后台扫描任务发布（`player_scan_*`，最多 256 首，`PLAYER_SCAN_MAX`，全部来自 SD 卡；UI 进页/检测到 SD 变化时请求重扫，见 `docs/player.md`）。
- 无播放进度条：VBR MP3 字节偏移百分比不准确，UI 刻意不展示。

## 7. 设置页布局

```text
y=38..60   "音量"   值列（右侧右对齐 x=232..312） "30%（默认）"
y=62..84   "总增益"  "+6dB / 0dB / -3dB"
y=86..108  "背光"   "60%"
y=110..132 "息屏"   "永不 / 15秒 / 30秒 / 60秒 / 120秒 / 300秒"
y=134..156 "重建播放列表" "有缓存 / 无缓存"
y=158..180 "重置NVS"   "按A重置"
y=204      "上/下选 A进入 左/右设 B返回"
```

（上图为设置项的示意排布，省略了「清除进度」与日志分组的 3 个日志项；实际共 10 个设置项，分属音频 / 显示 / 系统 / 日志四个分组。蓝牙不在设置页，见 §4。）

- 文本风精修：行距 24px；值列固定右缘（x=232 起 80px 宽，右对齐到 x=312），不同长度值尾端对齐；选中项整行青色不变。

- **总增益（全局前置增益）**：-12..+12 dB，1 dB 步进（默认 0 dB），左右键调节。作用在 DSP 链的分轨 ReplayGain 之后、主音量之前，扬声器与蓝牙两条路由共用；扬声器路径在其后仍有软限幅器兜底峰值，蓝牙路径做 16-bit 钳位。用于把偏小声的音源推过音量 100% 的响度，或压制过热的歌。
- **息屏（自动屏幕待机）**：空闲超时后背光关闭、ST7789 进入 DISPOFF 省电；任意按键唤醒恢复亮度。选项：永不 / 15 秒 / 30 秒 / 60 秒 / 2 分钟 / 5 分钟（默认 30 秒）。超时不计入充电/播放等活跃场景，仅由按键活动重置（见 `hw_lcd_activity()` / `hw_lcd_standby_tick()`）。
- 音量/总增益/背光/息屏持久化到 NVS（命名空间 `ui_cfg`：`volume` / `vol_bt`（蓝牙音量槽位）/ `gain_db`（dB×10）/ `backlight` / `standby_s`）；变更置脏位，800ms 无操作后一次写入（`ui_settings_flush`）。蓝牙主开关 `bt_on` 由蓝牙页持久化（同 `ui_cfg` 命名空间），默认关闭。
- 音量行显示**当前生效路由**的音量（蓝牙已连时为蓝牙槽位，否则喇叭槽位）；扬声器与蓝牙两个音量槽位的出厂默认均为 30%。
- 进入蓝牙页：在 Launcher 选中「蓝牙」磁贴按 A（自动置开蓝牙主开关、懒启动蓝牙栈）。
- 日志等级控制 `player` / `hw_audio` / `bluetooth_audio` 三个 tag 的运行时日志级别。

## 8. 蓝牙页布局

```text
y=2    标题 "蓝牙"                      右上（空）
y=38..158  设备列表 4 行（扫描期间实时增长）
y=172   "扫描中... N" / "N 个设备" / "无设备" / "已连接 <名>" / "配对码 NNNNNN"
        / "配对中 <名>" / "配对失败"
y=204  上下文提示（连接/断开/重试/扫描）
```

- 进入页面即 `bluetooth_audio_scan_start()`；设备列表只在 `bluetooth_audio_device_version()` 递增时重格式化（MAC 回退名不反复拼接）。
- 配对状态机：CONNECTING → PAIRING（SSP，显示 6 位配对码）→ OK/FAIL；失败 A 重试。
- 连接自动重试（3.5s 退避，最多 4 次）期间仍显示"连接中..."，由 `bluetooth_audio` 内部处理（见 `docs/bluetooth.md`）。

## 9. 阅读页布局

```text
y=2    书名（去扩展名，200px 内截断，橙）  右上 "12" 或 "12/345"
y=34   分隔线
y=36..212  正文 8 行（(0,36) 320×176，22px 行高；176 = 8×22，完整容纳 8 行）
y=198  左端 15 格文本进度条（x=8 起）+ 右端百分比（x=272 起 40px 宽，右对齐 x=312）← toast 临时整体替换
```

- 正文单 Label，`LV_LABEL_LONG_MODE_CLIP`；分页由引擎确定性完成（行宽按字体真实度量，全角标点行中/行尾一律半宽压缩），见 `docs/ebook.md`。
- 进度指示器：左端 15 格（x=8 起，~110px，`=` 已读、`-` 未读，四舍五入到格），右端百分比右对齐（x=272 起 40px 宽，右边缘 x=312；40px 可容纳 "100%" ≈36px，避免左端数字被裁）；toast 期间两者隐藏，仅居中 toast 文本。
- 总页数后台任务未算完时右上只显当前页。

## 10. 刷新节流

- 脏标记 + 16ms 周期：无变化时 `ui_refresh()` 直接返回（零 LVGL 调用）。
- 首次帧后 `hw_lcd_display_on()` 点亮背光（`lvgl_task` 轮询 `hw_lcd_first_flush_done()`）。
