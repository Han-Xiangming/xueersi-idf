# 小喵掌机 UI 与交互说明

> 本文档为**实现现状说明**（随代码更新）：描述 LVGL 9.5 自绘 UI 的页面结构、布局参数与按键映射。

## 1. 总体结构

```text
app/ui/ui.c（页面控制器，不依赖具体硬件）
  ├─ 主菜单（BIOS 风格，仅列出部分页面）
  ├─ 页面容器（ui_make_page，整屏 320×240，深底）
  └─ hint 状态行（页面底部，toast 提示临时占用）
```

- 入口：`ui_create()` 在 LVGL 任务中调用一次；`ui_refresh()` 由任务循环以 16ms 周期调用（`UI_REFRESH_PERIOD_MS`，main.c）。
- **按需刷新**：`s_ui_dirty` 脏标记 + `ui_external_changed()` 轮询（蓝牙设备列表/版本、配对状态、SD 挂载、播放器状态、电子书扫描/页数版本），只在真变化时重建页面内容；`ui_label_set()` 对未变化的文本直接跳过 LVGL set，60Hz 空转不产生重绘。
- 页面切换 `ui_enter_page()`：销毁旧页容器 → 按 `UI_PAGE_*` 重建 → 强制重绘；`ui_show_menu()` 隐藏/显示页面与菜单（无滑动动画）。
- 主题色：`UI_CYAN=0x00E0E0`（选中/强调）、`UI_GRAY=0x808080`（普通文本）、`UI_BG_DARK=0x000000`、`UI_TITLE=0xFF8000`（标题栏）。

## 2. 页面清单

| 页面 | 枚举 | 用途 | 构建函数 |
| ---- | ---- | ---- | ---- |
| 播放器 | `UI_PAGE_PLAYER` | MP3 列表（4 行）+ 播放状态 | `ui_build_player` |
| 书列表 | `UI_PAGE_EBOOK_LIST` | 先选来源（`<ALL>`+子目录），再递归扫描 `/sdcard/eBook/**/*.txt`（含内置 ROM 书） | `ui_build_ebook_list` |
| 阅读 | `UI_PAGE_EBOOK_READ` | TXT 电子书分页阅读 | `ui_build_ebook_read` |
| 蓝牙 | `UI_PAGE_BT` | A2DP 设备扫描/配对/连接 | `ui_build_bt` |
| 设置 | `UI_PAGE_SETTINGS` | 音量/背光/蓝牙/息屏/重置 | `ui_build_settings` |

- 主菜单只列出 4 项：`Music Player`、`电子书`、`设置`（蓝牙已并入设置页子页，见 §7）。SD 卡挂载状态不再单独成页，由播放器列表在卡插入/拔出时自动刷新。
- 电子书引擎在 `app/ebook/ebook.c`，UI 通过 `ebook.h` 公开 API 交互（见 `docs/ebook.md`）。

## 3. 版面参数

```text
标题栏：  y = 2      左对齐（橙色，书名/页面标题），右上角状态（灰，右对齐）
分隔线：  y = 34     1px 灰线，整屏宽
主菜单：  y = 38/68/98/128/158（5 项，30px 行距），光标 ">" 于 x=8，文本 x=18
         底部：左 "[n/4]"（x=4,y=206），右 "A:OK B:BK"（x=200,y=206）
列表页：  4 行 y = 38/68/98/128（30px 行距），光标 x=6，文本 x=16
         滚动窗口：选中项尽量居中（top = sel-1 起 4 行）
设置页：  7 行 y = 38/62/86/110/134/158/182（24px 行距），值列右对齐至 x=312；选中项整行青色
状态行：  y = 172（列表页状态）/ 198（SD、阅读页进度）；hint 一般 y=204
```

- 全局字体 `lv_font_cn_16`（16px 全字库 CJK，`components/fonts/lv_font_cn_16.c`，行高 30）；阅读页文本区直接用 30px 行高（无 line_space）。
- 所有文本 label 默认 304px 宽（`LCD_H_RES-16`）、`LV_LABEL_LONG_MODE_CLIP` 截断；列表行文本 288px 宽（`LCD_H_RES-32`）。

## 4. 按键映射

按键经硬件层消抖（见 `docs/hardware.md`）映射为 LVGL key：上/下/左/右/A(ENTER)/B(ESC)。

| 按键 | 主菜单 | 播放器 | 书列表 | 阅读页 | SD 卡 | 蓝牙 | 设置 |
| ---- | ---- | ---- | ---- | ---- | ---- | ---- | ---- |
| 上 / 下 | 移动选择 | 播放中=音量±；空闲=选曲 | 移动选择 | （预留） | — | 移动选择 | 移动选择 |
| 左 | — | — | — | 上一页 | — | — | 减小数值 |
| 右 | — | — | — | 下一页 | — | — | 增大数值 |
| A | 进入页面 | 播放/暂停 | 打开书 | 下一页 | 重扫 | 连接/断开/重扫 | 进入蓝牙页 |
| B | — | 播放中=停止；空闲=回菜单 | 回主菜单 | 回书列表 | 回主菜单 | 回设置页 | 回主菜单 |

- 阅读页：A 与 右键均为下一页，左键上一页；首页/末页时 toast 提示"第一页/最后一页"（不翻页）。
- 播放器音量：低于 10% 时 1% 步进（精细），之上粗步进（上下 5%、左右 10%）；播放中上下键才调音量，空闲时上下键移动选择。

## 5. toast 与按键反馈

- `set_action(msg)`：toast 在下一次刷新立即可见，显示 `UI_ACTION_MSG_MS=850ms`；快速连按只更新文字并顺延过期时间，不反复延迟。toast 期间 `s_ui_dirty` 保持置位，保证过期后刷新回正常文本。
- toast 与普通状态行共用 `s_ui.hint`：`ui_set_hint(normal)` 在 toast 激活期显示 toast，否则显示 normal。
- 阅读页 toast（下一页/上一页/第一页/最后一页）临时替换进度行，遮挡 SD 读取延迟。

## 6. 播放器页布局

```text
y=2    标题 "Music Player"（橙）        右上 ">> / || / --"（播放状态）
y=38..158  曲目列表 4 行（选中青色）
y=172   "空闲" / "无MP3文件" / 当前曲目名
y=204  "上/下选择 A播放 B返回" / "上/下音量 A暂停 B停止"
```

- 曲目列表由后台扫描任务发布（`player_scan_*`，最多 64 首，全部来自 SD 卡；UI 进页/检测到 SD 变化时请求重扫，见 `docs/player.md`）。
- 无播放进度条：VBR MP3 字节偏移百分比不准确，UI 刻意不展示。

## 7. 设置页布局

```text
y=38..60   "音量"   值列（右侧右对齐 x=232..312） "80%"
y=62..84   "总增益"  "+6dB / 0dB / -3dB"
y=86..108  "背光"   "60%"
y=110..132 "蓝牙"   "关 / 开 / 已连接"
y=134..156 "息屏"   "永不 / 15秒 / 30秒 / 60秒 / 120秒 / 300秒"
y=158..180 "重建播放列表" "有缓存 / 无缓存"
y=182..198 "重置NVS"   "按A重置"
y=204      "上/下选 A进入 左/右设 B返回"
```

- 文本风精修：行距 24px；值列固定右缘（x=232 起 80px 宽，右对齐到 x=312），不同长度值尾端对齐；选中项整行青色不变。

- **总增益（全局前置增益）**：-12..+12 dB，1 dB 步进（默认 0 dB），左右键调节。作用在 DSP 链的分轨 ReplayGain 之后、主音量之前，扬声器与蓝牙两条路由共用；扬声器路径在其后仍有软限幅器兜底峰值，蓝牙路径做 16-bit 钳位。用于把偏小声的音源推过音量 100% 的响度，或压制过热的歌。
- **息屏（自动屏幕待机）**：空闲超时后背光关闭、ST7789 进入 DISPOFF 省电；任意按键唤醒恢复亮度。选项：永不 / 15 秒 / 30 秒 / 60 秒 / 2 分钟 / 5 分钟（默认 30 秒）。超时不计入充电/播放等活跃场景，仅由按键活动重置（见 `hw_lcd_activity()` / `hw_lcd_standby_tick()`）。
- 音量/总增益/蓝牙/背光/息屏持久化到 NVS（命名空间 `ui_cfg`：`volume` / `vol_bt`（蓝牙音量槽位）/ `gain_db`（dB×10）/ `bt_on` / `backlight` / `standby_s`）；变更置脏位，800ms 无操作后一次写入（`ui_settings_flush`）。
- 音量行显示**当前生效路由**的音量（蓝牙已连时为蓝牙槽位，否则喇叭槽位）。
- 选中"蓝牙"按 A 进入蓝牙页（自动把 BT 主开关置开、懒启动蓝牙栈）。
- 日志等级控制 `player` / `hw_audio` / `bt_audio` 三个 tag 的运行时日志级别。

## 8. 蓝牙页布局

```text
y=2    标题 "蓝牙"                      右上（空）
y=38..158  设备列表 4 行（扫描期间实时增长）
y=172   "扫描中... N" / "N 个设备" / "无设备" / "已连接 <名>" / "配对码 NNNNNN"
        / "配对中 <名>" / "配对失败"
y=204  上下文提示（连接/断开/重试/扫描）
```

- 进入页面即 `bt_audio_scan_start()`；设备列表只在 `bt_audio_device_version()` 递增时重格式化（MAC 回退名不反复拼接）。
- 配对状态机：CONNECTING → PAIRING（SSP，显示 6 位配对码）→ OK/FAIL；失败 A 重试。
- 连接自动重试（2s 退避，最多 4 次）期间仍显示"连接中..."，由 `bt_audio` 内部处理（见 `docs/bluetooth.md`）。

## 9. 阅读页布局

```text
y=2    书名（去扩展名，200px 内截断，橙）  右上 "12" 或 "12/345"
y=34   分隔线
y=36..212  正文 8 行（(0,36) 320×176，22px 行高；176 = 8×22，完整容纳 8 行）
y=198  左端 15 格文本进度条（x=8 起）+ 右端百分比（x=272 起 40px 宽，右对齐 x=312）← toast 临时整体替换
```

- 正文单 Label，`LV_LABEL_LONG_MODE_CLIP`；分页由引擎确定性完成（行宽按字体真实度量，全角标点行中/行尾一律半宽压缩），见 `docs/ebook.md`。
- 进度指示器：左端 15 格（x=8 起，~110px，`=` 已读、`-` 未读，四舍五入到格），右端百分比右对齐（x=272 起 40px 宽，右边缘 x=312；40px 可容纳 "100%" ≈36px，避免左端数字被裁）；toast 期间两者隐藏，仅居中 toast 文本。
- 总页数后台任务未算完时右上只显当前页。

## 10. 刷新节流

- 脏标记 + 16ms 周期：无变化时 `ui_refresh()` 直接返回（零 LVGL 调用）。
- 首次帧后 `hw_lcd_display_on()` 点亮背光（`lvgl_task` 轮询 `hw_lcd_first_flush_done()`）。
